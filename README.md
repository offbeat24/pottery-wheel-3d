# 고요한 물레

마우스와 키보드로 물레를 돌리고 점토를 직접 빚어 주문 실루엣을 완성하는 브라우저용 3D 도예 게임입니다.

**[브라우저에서 바로 플레이하기](https://offbeat24.github.io/pottery-wheel-3d/)**

> 데스크톱 환경에서 마우스와 키보드가 필요합니다. 권장 해상도는 1440×900, 최소 해상도는 1280×720이며 Chromium에서 검증했습니다.

## 게임 소개

따뜻한 오후의 작은 공방에서 점토의 폭과 높이, 중심 구멍을 직접 조절해 주문 형태를 완성합니다. `아침 찻잔`, `햇살 사발`, `고요한 화병`의 세 주문이 있으며, 점토의 부피와 벽 두께를 유지하면서 목표 윤곽에 가까운 형태를 만드는 것이 목표입니다.

물레 속도와 점토 수분은 성형 효율과 안정성에 영향을 줍니다. 점토가 마르면 스펀지로 물을 바르고, 필요하면 예비 흙을 붙이거나 실로 윗부분을 잘라 높이를 다듬을 수 있습니다. 완성한 작품은 실루엣·높이·매끄러움으로 평가되며, 결과 화면에서 자유롭게 회전하고 확대해 볼 수 있습니다.

## 게임 플레이 방법

1. `Space`를 눌러 물레를 돌립니다.
2. 회전 중 점토를 좁히거나 넓히고, 높이와 중심 구멍을 조절해 주문 윤곽에 맞춥니다.
3. 점토가 마르면 스펀지를 적셔 표면에 물을 바릅니다. 적정 수분에서 물레 속도 34~85%를 유지하면 성형 효율이 가장 높습니다.
4. 필요하면 물레를 멈추고 본체 아래에 예비 흙을 붙이거나, 실로 윗부분을 잘라 높이를 정리합니다.
5. 물레가 완전히 멈춘 상태에서 `형태 확인하기`를 눌러 주문과 결과를 비교합니다.

### 조작법

| 상태 | 조작 | 동작 |
| --- | --- | --- |
| 항상 | `Space` 누르기 | 물레 가속 |
| 정지 중 | 좌드래그 | 시점 회전 |
| 정지 중 | 우드래그 | 시점 이동 |
| 정지 중 | 마우스 휠 | 확대·축소 |
| 회전 중 · 외벽 | 좌클릭 | 점토 좁히기 |
| 회전 중 · 외벽 | 우클릭 | 점토 넓히기 |
| 회전 중 · 중심 | 우클릭 | 구멍 열기·키우기 |
| 회전 중 · 중심 | 좌클릭 | 구멍 줄이기 |
| 회전 중 | 좌우 버튼 동시 누름 + 세로 드래그 | 점토 끌어올리기·누르기 |
| 수분 조절 | `W` 또는 물그릇 클릭 | 스펀지 적시기 |
| 스펀지를 든 상태 | 점토 좌드래그 | 물 바르기 |
| 스펀지를 든 상태 | 우클릭 | 스펀지 내려놓기 |
| 정지 중 | `흙 붙이기` | 본체 아래에 예비 흙 높이 추가 |
| 정지 중 | `C` 또는 `실 자르기` | 점토에서 수평으로 드래그해 윗부분 자르기 |
| 실 자르기 중 | `Esc` | 실 자르기 취소 |
| 정지 중 | `형태 확인하기` | 주문 윤곽과 결과 비교 |

`다시 시작`은 두 번 눌러야 현재 주문의 점토, 수분, 예비 흙, 스펀지와 잘린 조각을 초기화합니다.

### 평가 방식

| 평가 항목 | 반영 비율 |
| --- | ---: |
| 주문 실루엣 일치도 | 65% |
| 목표 높이 일치도 | 25% |
| 표면 매끄러움 | 10% |

결과 화면의 형태 평가액은 결과 피드백이며, 별도의 재화·상점·저장 기능으로 이어지지 않습니다.

## 활용 기술 스택

| 구분 | 기술 | 활용 내용 |
| --- | --- | --- |
| 3D 렌더링 | Three.js | 공방, 물레, 점토 메시와 손 동작 렌더링 |
| 게임 개발 | TypeScript | 점토·수분·물레·입력·주문·채점 로직 |
| 화면 구성 | HTML, CSS | 주문 카드, 작업 정보, 조작 안내와 결과 화면 |
| 개발·빌드 | Vite | 로컬 개발 서버와 프로덕션 번들 생성 |
| 단위 테스트 | Vitest | 수학 모델과 상태 전이 검증 |
| 브라우저 테스트 | Playwright | 1440×900 Chromium 환경의 실제 조작 흐름 검증 |
| 자동화·배포 | GitHub Actions, GitHub Pages | 검증 자동화와 웹 배포 |

게임은 별도 백엔드 없이 브라우저에서 실행되며, 계정·저장·동기화·멀티플레이 기능은 현재 포함하지 않습니다.

## AI 활용 방법

AI는 게임 실행 기능이 아니라 개발 협업 도구로 활용했습니다.

- 팀원이 게임 목표, 현실성 수준, 기능 우선순위와 최종 채택 여부를 결정했습니다.
- OpenAI Codex가 자연어 요구를 기능별 작업으로 구조화하고 TypeScript·Three.js 코드, 테스트, 문서를 함께 작성했습니다.
- BASS 에이전트 하네스로 작업 범위, 수용 기준, 검증 결과를 기록했습니다.
- 구현과 별도로 Design, Test, Simplicity 관점의 독립 검토를 거쳐 화면, 회귀 위험, 과도한 복잡성을 확인했습니다.
- TypeScript 타입 검사, Vitest 단위 테스트, Playwright E2E 테스트와 프로덕션 빌드로 AI 산출물을 검증했습니다.

게임 실행 중에는 AI 모델이나 외부 AI API를 호출하지 않습니다.

## 로컬 실행

Node.js 20.19 이상이 필요합니다.

```bash
git clone https://github.com/offbeat24/pottery-wheel-3d.git
cd pottery-wheel-3d
npm ci
npm run dev
```

전체 검증은 다음 명령으로 실행합니다.

```bash
npm run verify
```
