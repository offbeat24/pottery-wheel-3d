# 고요한 물레

키보드와 마우스로 물레를 돌리고 점토를 빚는 브라우저용 3D 프로토타입입니다.

## 팀 AI 작업 시작

저장소를 처음 내려받은 뒤 프로젝트 루트를 Codex나 Claude에서 열고 다음 한마디만 입력합니다.

```text
작업시작
```

에이전트가 의존성, 고정된 BASS 하네스, Playwright, 저장소 구조와 전체 검증을 준비한 뒤
현재 Product Seed, 변경 가능한 구현 가설, 검증 결과와 추천 첫 작업을 보고합니다. 같은 환경에서는
최초 한 번만 필요하며, 이후 팀원은 BASS 명령이나 기록 파일을 직접 관리하지 않고 자연어로
목표만 전달합니다. 하네스 또는 lockfile이 바뀌면 에이전트가 필요한 초기 세팅을 다시 수행합니다.

동시 작업은 각자 별도 branch 또는 worktree에서 진행합니다. `DESIGN.md`, `src/main.ts`,
전역 스타일처럼 충돌 가능성이 큰 파일은 한 작업만 소유합니다. PR 전 검증은 에이전트가
`npm run verify`로 수행하며 GitHub Actions가 같은 기준을 다시 확인합니다.

## 실행

```bash
npm install
npm run dev
```

## 조작

- `Space`: 누르는 동안 물레 가속
- 정지 중 좌드래그: 시점 회전
- 정지 중 우드래그: 시점 이동
- 정지 중 마우스 휠: 확대·축소
- 회전 중 좌클릭: 점토 좁히기
- 회전 중 우클릭: 점토 넓히기
- 회전 중 좌우 동시 클릭 + 세로 드래그: 점토 끌어올리기·누르기
