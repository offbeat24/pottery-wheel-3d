# 고요한 물레

키보드와 마우스로 물레를 돌리고 점토를 빚어 주문의 형태를 맞추는 브라우저용 3D 게임입니다.

## 팀 AI 작업 시작

저장소를 처음 내려받은 뒤 프로젝트 루트를 Codex나 Claude에서 열고 `작업시작`이라고
입력합니다. 이후에는 자연어로 목표만 전달하면 됩니다.

## 실행

```bash
npm install
npm run dev
```

## 조작

- `Space`: 누르는 동안 물레 가속
- 정지 중 좌드래그: 시점 회전
- 정지 중 우드래그: 시점 이동
- 정지 중 마우스 휠: 확대·축소
- 회전 중 외벽 좌클릭: 점토 좁히기
- 회전 중 외벽 우클릭: 점토 넓히기
- 회전 중 중심 우클릭: 구멍 열기·키우기
- 회전 중 중심 좌클릭: 구멍 줄이기
- 회전 중 좌우 동시 클릭 + 세로 드래그: 점토 끌어올리기·누르기
- `W` 또는 물그릇 클릭: 스펀지 적시기
- 젖은 스펀지로 점토 좌드래그: 물 바르기
- 스펀지를 든 상태에서 우클릭: 스펀지 내려놓기
- 정지 중 `흙 붙이기`: 본체 아래에 예비 흙 높이 추가
- 정지 중 `C` 또는 `실 자르기`: 점토에서 수평으로 드래그해 그 높이의 윗부분 자르기
- 정지 중 `형태 확인하기`: 주문 윤곽과 즉시 비교

컵, 사발, 화병의 목표 실루엣과 높이를 맞추면 실루엣·높이·매끄러움으로 형태 점수를
계산합니다. 결과표의 `3D 전체 보기`에서 만든 점토를 자유롭게 돌려볼 수 있습니다.
