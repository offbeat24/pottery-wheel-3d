# 고요한 물레

키보드와 마우스로 물레를 돌리고 점토를 빚는 브라우저용 3D 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

## 조작

- `Space`: 누르는 동안 물레 가속
- `W`: 누르는 동안 흙에 물 묻히기
- 정지 중 좌드래그: 시점 회전
- 정지 중 우드래그: 시점 이동
- 정지 중 마우스 휠: 확대·축소
- 회전 중 좌클릭: 점토 좁히기
- 회전 중 우클릭: 점토 넓히기
- 회전 중 좌우 동시 클릭 + 세로 드래그: 점토 끌어올리기·누르기

컵, 사발, 화병의 목표 실루엣을 맞추고 물레를 멈춘 뒤 결과를 확인하세요.

## 소리

효과음은 Web Audio로 합성하므로 별도 파일이 필요 없습니다.
배경음악을 넣으려면 `public/bgm.mp3` 를 추가하세요 — 자세한 내용은 `public/README.md` 참고.
