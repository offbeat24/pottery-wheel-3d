# 고요한 물레

키보드와 마우스로 물레를 돌리고 점토를 빚는 브라우저용 3D 프로토타입입니다.

## 팀 AI 작업 시작

저장소를 처음 내려받은 뒤 프로젝트 루트를 Codex나 Claude에서 열고 다음 한마디만 입력합니다.

```text
작업시작
```

에이전트가 의존성, 고정된 BASS 하네스, Playwright, 저장소 구조와 전체 검증을 준비한 뒤
현재 Product Seed, 변경 가능한 구현 가설, 검증 결과와 추천 첫 작업을 보고합니다. 같은 환경에서는
최초 한 번만 필요하며, 이후 팀원은 BASS 명령이나 기록 파일을 직접 관리하지 않고 자연어로
목표만 전달합니다. 하네스 또는 lockfile이 바뀌면 에이전트가 필요한 초기 세팅을 다시 수행합니다.
BASS의 `common`, `web`, `server` 계약이 함께 적용되므로 향후 백엔드·API·데이터베이스를
추가해도 같은 자연어 작업 흐름과 검증 기준을 확장해 사용합니다.

동시 작업은 각자 별도 branch 또는 worktree에서 진행합니다. `DESIGN.md`, `src/main.ts`,
전역 스타일처럼 충돌 가능성이 큰 파일은 한 작업만 소유합니다. PR 전 검증은 에이전트가
`npm run verify`로 수행하며 GitHub Actions가 같은 기준을 다시 확인합니다.

## 실행

```bash
npm install
npm run dev
```

## 조작

- `Space`: 누르는 동안 물레 가속
- 정지 중 좌드래그: 시점 회전
- 정지 중 우드래그: 시점 이동
- 정지 중 마우스 휠: 확대·축소
- 회전 중 외벽 좌클릭: 점토 좁히기
- 회전 중 외벽 우클릭: 점토 넓히기
- 회전 중 중심 우클릭: 구멍 열기·키우기
- 회전 중 중심 좌클릭: 구멍 줄이기 (구멍 없이도 성형·마감 가능)
- 회전 중 좌우 동시 클릭 + 세로 드래그: 점토 끌어올리기·누르기
- `W`: 마른 점토에 물 적시기
- 정지 중 `흙 붙이기`: 본체 아래에 180g 예비 흙덩이 접합
- 정지 중 `H` 또는 `손잡이`: 손잡이 부착 후 폭·높이·두께·위치 조절
- `성형 마치기` 후 `건조 시작`: 현재 수분을 보존한 채 시간 압축 건조를 진행해 가죽경도에 도달

컵, 사발, 화병의 목표 실루엣을 맞춘 뒤 무유약 또는 유약을 고릅니다. 유약은 점토 표면을
마우스로 직접 칠하고 900~1300°C 가마 온도를 설정해 굽습니다. 유약 종류·도포율·온도에
따라 점수와 완성 색이 달라지며 결과표의 `3D 전체 보기`에서 완성품을 자유롭게 돌려볼 수
있습니다. 흙의 부피는 성형 중 보존되므로 높이거나 넓힐수록 벽이 얇아지고, 수분이 마르면
점토가 밝고 분말감 있게 변합니다. 수분과 RPM에 따라 같은 손동작의 효과와 실패 위험도
달라집니다.

성형을 마쳤다고 점토가 즉시 마르지는 않습니다. 건조 단계에서 수분계와 표면색이 연속적으로
변하며, 가죽경도에 도달한 뒤에만 마감을 선택할 수 있습니다.
